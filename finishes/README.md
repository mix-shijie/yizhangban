# finishes/ · 放自己的花色图片

1. 把图片放进这个文件夹，文件名用英文、数字、短横线，例如 `store-oak-01.jpg`。
2. 在根目录 `config.json` 的 `finishes` 里加一项：

```json
{ "id": "store-oak-01", "name": "北欧白橡", "kind": "直纹", "image": "finishes/store-oak-01.jpg", "rough": 0.6 }
```

## 图片要求

| 项目 | 要求 |
|---|---|
| 比例 | 竖版 1:2（宽:高），代表一整张 1220 × 2440 mm 的板 |
| 尺寸 | 建议 1024×2048 像素，最大 2048×4096 |
| 方向 | 木纹顺着竖向（板长方向） |
| 格式 | JPG 或 PNG，单张 1 MB 以内 |
| 拼接 | 最好上下左右能无缝拼接；程序会在不同板件上随机取位置 |

比例不对会自动居中裁成 1:2。只拍了一小块小样的照片，铺到整板上纹理会显得偏大，最好先平铺拼成整板比例。

`rough` 是表面粗糙度 0–1：亮光面约 0.3，哑光约 0.6。`kind` 写 `纯色` 时表面凹凸会更弱。

图片会随网站一起公开，请只放你有权公开的图片。
